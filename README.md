## 📌 About the Project

This is a personal portfolio website developed using **Python Flask** for the backend, HTML and CSS for the frontend, and SQLite for storing contact form messages.

The website provides visitors with an overview of my portfolio and a way to get in touch with me through the contact form.

## ✨ Features

- Clean and user-friendly interface
- Responsive portfolio design
- Personal illustration and styling
- Contact form for visitors
- Form submission success page
- SQLite database integration for storing messages
- Live deployment using PythonAnywhere

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/MALAVIKAVINOD19/my-portfolio.git
```

**2. Navigate to the project folder**

```bash
cd my-portfolio
```

**3. Install the required packages**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

**5. Open the website**

Visit:

```text
http://127.0.0.1:5000/
```

## 🗄️ Database

The project uses SQLite to store messages submitted through the contact form.

The database and messages table are automatically created when the Flask application starts.
